# ZhangWei Prompts Data Rules

- This repository is the public source of truth for the ZhangWei prompt gallery.
- Store one prompt per JSON file under `data/prompts/<shard>/<id>.json`.
- Never commit secrets, tokens, cookies, private keys, or private editorial notes.
- Generated gallery assets are outputs; prompt JSON, collection JSON, proof assets, and schemas are canonical inputs.
- Run `npm run verify` before pushing changes.
- Do not publish or deploy the gallery from this repository.
